# 資金の流れと次の買い手を考える編集ガイド

主要候補では、企業の変化が利益につながる条件と、その変化を投資家が評価する条件を分けて説明する。良い材料が出たこと、株価が上がったこと、特定の投資家が買ったことは、それぞれ別の確認事項として扱う。

日刊の編集手順は [daily.md](../prompts/daily.md)、単発の解説記事は [explain.md](../prompts/explain.md) に従う。このガイドは銘柄の推奨や個人の売買手法の再現ではなく、記事で考える問いと確認方法を定める。

## 次の買い手と評価のきっかけ

日刊の核になる1〜2候補について、どの投資家が、何を理由に買いたくなるかを考える。成長株ファンド、配当重視の投資家などの属性だけを並べず、その候補の具体的な材料との関係を書く。

次に公表される数字、その数字で買う理由がどう変わるか、予想どおりでも株価が上がらない場合を順に説明する。価格・出来高で何を確認するかも示す。投資家の属性を裏付けられないときは、無理に分類せず「どんな数字を重視する投資家か」を説明する。

例えば、受注が増えた企業なら、成長を重視する投資家が売上の伸びを評価する可能性がある。ただし、採算や納入時期が分からなければ、利益成長を評価する買い手が増えるかは分からない。次の決算で何が分かれば、その不確実性が減るのかを説明する。

想定する買い手は編集者の仮説として示す。大量保有報告などの資料で保有を確認した場合も、報告対象日と公表日を区別し、その投資家の動機や現在の売買まで推測しない。株価・出来高から買い手の属性は特定できない。

大口資金を想定するなら、時価総額、売買代金、浮動株など、取得できた指標から規模と流動性を確認する。データの対象日と出典を付け、実際にどの金額まで売買できるかを根拠なく算出しない。特定の発信者への依存が疑われる場合も、発信前後の反応を確認し、株価操縦や売り抜けを憶測で認定しない。

## 材料と株価の反応

Xの投稿数・投稿者数は、収集したリスト内での関心を示す。市場全体の人気、資金流入、買いの成立を示す数字にはしない。

価格を調べる前に、材料の公表日時に合う比較期間を決める。通常取引終了後の発表なら、公表前の終値と次の取引日の反応などを比較する。比較する市場、通貨、通常取引か時間外か、データの取得時点も明記する。取得できた範囲で出来高・売買代金や市場・業種指数との違いを確認し、分割調整など比較条件をそろえる。

| 確認したこと                       | 記事で説明すること                                                 |
| ---------------------------------- | ------------------------------------------------------------------ |
| 材料公表後に価格と出来高が増えた   | 実際の反応と比較期間。買い手の属性や上昇原因は別途検証する         |
| 話題は増えたが価格は反応していない | リスト内の関心と価格の反応の違い。評価を変える次の材料             |
| 好材料が出ても価格が下がった       | 織り込み済み、評価倍率、市場下落、別の悪材料などの説明を調べた結果 |
| 価格データを取得できなかった       | 反応は未確認。確認できた投稿者の見方と区別する                     |

反応を見た後に、都合のよい安値や高値へ比較基準を変えない。原因を確認できなければ、価格の観測結果と原因不明であることをそのまま書く。

## 業績と需給の仮説を別々に追跡する

既存の型、判定、取り上げた理由、仮説、売買条件、次の行動を保つ。仮説欄は同じ行に `業績：…／需給：…` と書く。価格データが不足するなら、需給の判断が未確認であることを明記する。

| 仮説 | 確認する対象                                             | それだけでは確認できないこと                       |
| ---- | -------------------------------------------------------- | -------------------------------------------------- |
| 業績 | 受注、納入、売上、利益率などの対象期の実績               | 株価上昇だけで利益の改善を確認したとは扱えない     |
| 需給 | 評価のきっかけと、事前に決めた期間の価格・出来高等の反応 | 価格上昇だけでは想定した買い手の参加を確認できない |

追跡項目は、記事末尾の「次回更新する項目」に別々の番号で置き、会社名と「業績」「需給」を項目名に含める。現行Wikiは両者を自動分類しない。各項目を既存の手順で個別にレビューし、結果を記録する。

業績の確認には対象期・指標・比較基準・公式資料・確認時期、需給の確認には対象市場・指標・比較期間と基準・データ出典・確認時期を含める。公式日程が未公表なら、その事実と内部の再確認予定を区別する。需給の確認では、会社IRに代えて価格・出来高などを提供するデータ元も必要になる。

事実を一つ確認しただけなら `observed` を使う。仮説の支持・反証は、その仮説の条件がそろったかを見て判断する。資料未公開・取得失敗なら `unavailable` と再確認日時を記録する。価格の反応があっても買い手の属性が不明なら、その部分を未確認として残す。

買う理由と出口の型はそろえる。業績型で需給が良くなっただけなら業績条件の成立とは扱わず、需給の変化を理由に判定を変える際も、どの条件を満たしたかを書く。「雰囲気が変わった」だけで利確や損切りを決めず、観測できる指標と比較基準で説明する。個人の集中投資比率や取得価格を、読者共通のルールへ転用しない。

## 受注発表を扱う記入例

以下は書き方を示す架空の例。実在企業の数値、発表日、価格データを使っていない。既存記事の公開内容を更新したものでもない。実際の号では、対象期、確認済みの比較基準、日付、出典をそろえて書く。

### 受注が増えたら、株価も評価される？

受注の増加は売上が伸びる可能性を示すが、利益の増加まで確定するものではない。納入の時期と採算を確認する必要がある。

### 次の買い手と評価のきっかけ

成長を重視する投資家が、受注を継続的な売上成長の根拠として評価する可能性がある。ただし、利益を出せる受注かが分からなければ、買う理由としては不十分だ。次の決算で納入・売上計上と利益率を確認できれば、評価を見直すきっかけになり得る。実際にその投資家が買っているかは未確認である。

### 材料に対する株価の反応

この例では価格・出来高を提示していないため、反応は未確認とする。実際の記事では発表前後の取引日とデータを示し、市場全体の値動きも確認する。株価が上がっても、想定した買い手が参加した証拠とはしない。

- **取り上げた理由**：受注発表をきっかけに、納入から利益までの条件と、市場の評価が変わる条件を確認するため。
- **仮説**：業績：予定どおり納入でき、採算が保たれれば売上・利益が増える。／需給：利益への貢献が決算で確認されれば、成長を重視する投資家の評価が変わる可能性がある。実際の買い手と価格の反応は未確認。
- **現在の判定**：監視。価格データと業績の比較基準が不足している。
- **次の行動**：対象期の納入・売上・利益率と、材料公表前後の価格・出来高を別々に確認する。数値基準がそろうまでは買う条件を成立扱いにしない。

実際の号では既存の買う条件・利確条件・損切り条件も記載する。この例では価格や比較基準を創作して埋めない。

## 長さと日本語の推敲

冒頭の判定は短く保ち、詳しい説明は主要候補へ置く。理由、条件、反対の可能性、次の確認事項に必要なら、従来より長くなってよい。すべての候補へ同じ段落を機械的に追加せず、重複する説明や一般論を削る。

初稿は `yomiyasu` で推敲し、主張・比重・断定の強さを保つ。本人の投資スタイルを紹介する文章にはせず、毎日の材料に応じた分析として書く。
